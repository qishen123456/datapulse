# 03 · 模拟数据集与数据表设计

> 为后续生成模拟 CSV 提供蓝本。采用「维度表 + 事实表」星型结构，便于智能问数做多维下钻与聚合。维度与气价、供销差标准已对齐城市燃气行业通用口径。

## 一、数据规模与范围（模拟设定）

| 项 | 设定 |
|---|---|
| 主体 | 江城燃气股份有限公司（虚构） |
| 分公司 | 滨江 / 沙湖 / 经开 / 临港 / 高新 / 高压输配（6 个） |
| 用户规模 | 居民约 310 万户、工商业约 1.8 万户 |
| 年供气量 | 约 19 亿方 |
| 气价 | 居民 2.45/2.70/3.45、工商业 3.60 |
| 供销差率标准 | 新建 4.5%、运行 3 年以上 3.5% |
| 时间范围 | 2024-01 ~ 2026-09（33 个月） |
| 财务特征 | 年收入约 50 亿、净利润为负（购销倒挂） |
| 模拟粒度 | 事实表按「月 × 分公司 × 客户类型」聚合 |

> ⚠️ 全部为**虚构演示数据**，不指向任何真实企业，仅用于验证问数链路与 SQL 聚合正确性。

## 四、模拟数据生成规则（供后续脚本参考）

1. **量价联动**：销气量按客户类型×月份×分公司生成；居民冬高夏低、工业平稳、商业稳定；销气收入 = 量 × 气价（居民按阶梯加权均价，工商 3.60）。
2. **购销倒挂设定**：综合购气均价设 2.6~2.9 元/方（高于居民一档 2.45），使居民结构主导下的综合售价贴近或低于成本，复现"倒挂亏损"；全年净利润为负。
3. **供销差**：购气量 = 销气量 ÷ (1 − 供销差率)；供销差率按分公司在 3%~6% 分布，**设 1~2 家分公司超 3.5%/4.5% 核定标准**，用于演示"定位超标"。
4. **应收账款**：回收率 85%~98%，工商大客户设长账龄段，制造欠费风险案例。
5. **安全数据**：安检覆盖率逐月爬升、隐患整改率 90%+，GIS 入库率逐年提升，可埋 1~2 个未整改隐患作稽核点。
