# 01 · 燃气业务全景与行业知识

## 一、产业链定位

```
上游气源 ──► 城市燃气公司（城燃） ──► 终端用户
(管道长协/气源干网/LNG)   (本 demo 主体：江城燃气)   (居民/商业/工业)
```

江城燃气处于产业链**中游**：上游借国家气源干网 + 长协管道气形成多路气源保障；下游服务 310 万居民用户 + 1.8 万工商用户。商业模式核心是**购销价差（毛差）**——而江城燃气的现实困境，正是这个毛差被**压成了负值**。

## 二、价值链四个环节

1. **气源采购**
   - 长协管道气：与上游签订年度合同（基准价 + 浮动）；
   - 管道气 / LNG 现货：用于调峰补缺，价格随市场波动；
   - 采购成本 = 门站计量气量 × 购气单价 + 管输/代输费用。

2. **输配与调压**
   - 门站接收上游气 → 高压/中压/低压管网（共约 1.7 万公里）→ 调压站 → 用户端；
   - 关键资产：管网里程（分压力等级）、门站、调压站、LNG 气化站。

3. **销售与计量**
   - 居民用户：阶梯气价（一/二/三档 2.45/2.70/3.45 元/方），按表抄见量计费；
   - 工商业用户：非居民气价 3.60 元/方，多配大表 + 远传/IC 卡；
   - 计量痛点：IC 卡膜式表"基表（机械读数）"与"控制器（电子显示）"偏差，以机械读数为结算基准。

4. **服务与安全**
   - 抄表收费、客服（统一服务热线）、入户安检、管网巡查、抢修抢险（多中心 + 24 小时备勤）；
   - 工程安装：报装 → 施工 → 验收 → 通气，产生"安装工程收入"；瓶改管是重点增量。

## 三、客户分类与气价特征（模拟气价）

| 客户类型 | 典型对象 | 用气特征 | 气价 |
|---|---|---|---|
| 居民 | 住宅家庭 | 户数极多（310 万）、用量小、冬高夏低 | 阶梯 2.45 / 2.70 / 3.45 元/方 |
| 商业 | 餐饮、酒店、洗浴 | 用量中等、稳定 | 非居民 3.60 元/方 |
| 工业 | 锅炉、窑炉、生产线 | 用量大、波动大 | 非居民 3.60 元/方 |
| 公益机构 | 学校、养老 | 政策性优惠 | 2.58 元/方 |

> **关键结论**：江城燃气用户结构极度偏居民（310 万户 vs 1.8 万工商），而居民气价受政府管制、低于购气成本，这是购销倒挂、经营亏损的**结构性主因**。

## 五、关键行业术语速查（行话版）

| 术语 | 解释 |
|---|---|
| 门站 | 接收上游天然气、计量并调压后送入城网的场站 |
| 供销差 / 输差 | 行内常叫"输差"，购进气量与售出气量的差，反映损耗 |
| 供销差率 | 输差占购气量的比率；地方核定线一般 3.5%~5%，超了成本自己扛，低了收益要和用户分成 |
| 毛差 | 卖气均价 − 买气均价（元/方）；城燃利润的命根子 |
| 购销倒挂 | 卖气价低于供气成本，卖得越多亏越多 |
| 顺价 / 顺价机制 | 把上游涨价疏导到终端气价；"顺价不畅"就是倒挂改不了 |
| 压非保民 | 合同气量优先保居民、压缩非居民供应，倒挂的重要成因 |
| 接驳 | 新用户报装、接通燃气的工程，安装工程收入的主要来源 |
| 阶梯气价 | 居民按年用量分档计价，用得越多单价越高 |
| 气化率/渗透率 | 已用气户数 ÷ 可供气户数 |
| 抄见量 / 估抄量 | 实抄表读数 / 没抄到按规则估的量；估抄率高说明计量质量差 |
| 瓶改管 | 瓶装液化气用户转管道天然气，餐饮是重点 |
| 到访不遇 | 入户安检时用户家里没人、长期进不了门——安检的最大痛点 |
| 燃气三件套 | 金属波纹管、燃气泄漏报警器、自闭阀（用户端安全装置） |
| 基表 / 控制器 | IC 卡表的机械计量 vs 电子显示，结算以机械读数为基准 |
| 抢维修 | 抢修 + 维修的合称，燃气公司 7×24 值守的业务 |
| 公服用户 | 学校、医院、养老院等公共服务用户，执行居民类气价 |
| 大用户直供 | 工业大户绕过城燃直接向上游购气，行业新挑战 |
| 长协 / 现货 | 长期合同气 / 现货市场（LNG）采购 |

## 六、与财务稽核的关联点

- 销气收入 = 销气量 × 对应气价，需核对**抄见量**与**计费量**是否一致；
- 购气成本需与上游**结算单、发票**对账（三单一致）；
- 安装工程收入需确认**完工/验收**节点，判断收入确认时点；
- 应收账款需看**账龄**与**回收率**，评估坏账风险；
- 计量偏差（基表 vs 控制器）和偷盗气直接侵蚀供销差，是稽核重点。
