# 飞书字段字典

数据均为虚构。数量单位方，金额元，比例用 0–1 小数。月份和组织编码设文本，日期设日期，数值列设数字。

## gas_org.csv

| 字段 | 中文含义 | 飞书类型 |
|---|---|---|
| business_key | 业务唯一键 | 文本 |
| org_id | 组织编码 | 文本 |
| org_name | 组织名称 | 文本 |
| parent_id | 上级组织编码 | 文本 |
| org_level | 组织层级 | 数字 |
| org_path | 组织编码路径 | 文本 |
| org_name_path | 组织名称路径 | 文本 |
| sales_enabled | 是否有销售职责 | 数字 |
| data_version | 模拟版本 | 文本 |
