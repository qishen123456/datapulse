# 燃气公司智能问数 Demo（业务知识库）

> 定位：为「燃气经营与财务稽核」场景的智能问数路演准备一套**业务知识底座**。
> 本目录只做业务知识沉淀，不涉及系统代码。后续将据此生成模拟数据 CSV，上传飞书后由系统功能同步入库，形成可问数的 demo 数据集。

## 演示主体

**江城燃气股份有限公司（江城燃气）** —— 某华中省会城市的城市燃气经营主体，年供气约 19 亿方、服务 310 万居民用户。核心矛盾是**"规模大却不赚钱"**：年收入约 50 亿元，但因购销倒挂，净利润持续为负。

> 本 demo 为**虚构演示**：公司名称、组织、数字均为模拟，不指向任何真实企业；业务特征与指标体系反映的是城市燃气行业普遍关心的问题（购销倒挂、供销差、计量、回款、安全）。

## 核心设定

| 项 | 设定 |
|---|---|
| 演示主体 | **江城燃气股份有限公司**（虚构） |
| 组织架构 | 6 家分公司：滨江 / 沙湖 / 经开 / 临港 / 高新 / 高压输配 |
| 客户规模 | 居民约 310 万户、工商业约 1.8 万户 |
| 年供气量 | 约 19 亿方 |
| 管网 | 约 1.7 万公里 |
| 气价 | 居民阶梯 2.45 / 2.70 / 3.45 元/方、工商业 3.60 元/方 |
| 供销差率标准 | 新建管网 4.5%、运行 3 年以上 3.5%（地方价格联动核定） |
| 数据时间范围 | 2024-01 ~ 2026-09（33 个月） |

> ⚠️ 全部为**虚构演示数据**，不指向任何真实企业，不得作为经营或稽核结论引用。
