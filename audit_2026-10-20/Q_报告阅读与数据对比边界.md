# 报告阅读与数据对比边界（2026-10-22）

## 本次完成

- 右侧分析面板增加「报告」，支持独立 HTML 预览和放大阅读；答案底部分别提供「HTML 分析报告」和「分析过程」。
- 普通问数报告包含现有 AI 解读、实际返回规模、带数值的图表及明细表，下载使用同一 HTML 模板。研究报告继续使用分支证据、发现引用、边界与待补证模板。
- 自动条形图、折线图及配置图表显示数值标签，密集标签避让；图中使用紧凑数值，明细和 HTML 报告保留精确数值。
- 维度识别优先选择变化的实体名称，共同月份不会抢占分公司名称作为对照标题。编码不参与数值指标推断。
- HTML 转译只展示已有内容，不新增模型请求；文本转义并放入禁用脚本的 iframe，不能把排版误当成新一轮分析。

## 现在如何分析

原问题仍走服务端的实际模型查询生成、审核、受控执行与业务解读流程。拿到结果后，选两行仅进行浏览器端逐字段差值计算（右减左），没有再次调用模型，不重新取数，也不验证因果。第三项替换右侧选项。带入追问只填写草稿，发送后才再次进入现有问数流程。

例如同为 2026-09：经开销气量 36,060,044 方，滨江 33,055,044 方；右减左为 -3,005,000 方。这只说明当月规模差异，不说明经营效率或差异原因。

当前对照尚无完整的时间、粒度、单位可比性契约，追问传递主要是对象名称及原问题文字。它是事实查看工具，不能称为完成了深入对比分析。

## 建议下一阶段：复用主理人，新增对比分析任务契约

1. 选择对象后先即时展示事实差值，保持交互响应，不调用模型做简单算术。
2. 用户点击「深入分析差异」，提交结构化选择上下文：来源查询/结果集、数据集 ID、实体标识、所选行、时间区间、指标及单位、粒度、分析目标。
3. 服务端重新校验组织权限、数据集可见性和来源有效性；客户端选中数据不能充当授权证明。
4. 主理人调用口径对齐/可比性技能：确认相同指标、统计周期和粒度，发现冲突时先澄清。
5. 分析专家提出可验证的分析方向；现有查询专家按需补取历史、客户结构、计划目标等数据，现有审核专家校验 SQL 和结果。
6. 事实差值、变化率等由确定性计算负责；零分母、缺失值、单位不明应明确标记，不能由模型补造。
7. 对复杂归因沿用已获授权的高阶并行取证、重试预算和证据汇合机制。是否走研究流程仍由控制台角色策略决定。
8. 输出事实、证据支持的解释、待验证假设与边界，并把发现链接到对应查询结果。

不建议新增独立主理人，也不建议每次点选都自动发起多专家研究。可先把「对比分析」作为现有分析与报告专家的专用技能；只有评测证明该任务需要独立工具、知识和策略时，再拆成独立专家。
