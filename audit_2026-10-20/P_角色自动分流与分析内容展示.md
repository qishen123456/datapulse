# 角色自动分流与分析内容展示

日期：2026-10-22。本轮针对三个体验问题改造：输入框只在顶部运动、用户必须选择问数路径、过程区只有空泛的状态名称。

## 产品参考与采用方式

[火山引擎智能问数文档](https://docs.volcengine.com/docs/DataAgentPrivate/IntelligentQueryAgent-1?lang=zh) 提供分析过程、分析参数与过程代码的查看入口；[Looker 对话分析文档](https://docs.cloud.google.com/looker/docs/conversational-analytics-looker-data-agents-dashboards?hl=en) 将执行说明、生成的查询与底层数据关联。这里借鉴信息逐层展开的方式，没有复制它们的内部实现或宣称功能等价。

主画布直接显示“分析思路与依据”，右侧继续提供进展、查询依据、诊断。阶段显示收为紧凑路径，避免主画布和右侧都堆四块空状态。

## 路径与权限

- 用户侧移除普通问数/高阶研究切换、路径徽标及队列中的模式标签；统一问数入口和欢迎内容。
- 新问题与排队问题不再发送指定路径，执行时由服务端重新计算，不能沿用排队时的旧模式绕过新策略。
- 控制台“双路径问数控制 → 展开设置 → 按角色分配问数路径”支持普通用户、业务管理员、管理员、超级管理员分别指定路径，或清空以沿用数据集/默认策略。
- 明确角色分配优先；高阶总开关、角色开放名单、功能权限仍共同限制准入。赋予路径不扩大组织或数据集权限。旧客户端提供的路径不能覆盖明确角色分配。
- 原内部 API 的合法显式路径参数保留兼容；未明确分配角色时仍走原有受授权保护的策略。用户界面不会发送此参数。

## 真正展示的分析内容

| 时点 | 展示内容 | 数据来源 |
| --- | --- | --- |
| 任务受理 | 本次分析目标 | 用户原始问题 |
| 资产准备 | 数据集、问题中的时间词、字段定义/表关联/样例数量 | 已读取的数据集上下文；时间词只做原文提取，不推断额外筛选 |
| 查询生成 | 查询专家生成的简短方案说明、实际查询中的聚合方法 | 模型公开方案字段与生成的 SQL；此时明确仍待审核 |
| 审核 | 审核是否通过、下一步范围注入与预检 | 实际审核结果 |
| 执行预检 | 执行计划预检结果 | 数据库预检回调 |
| 数据返回 | 行数、实际结果列 | 实际数据执行响应 |
| 合理性核验 | 空值、规模与异常提示 | 确定性数据断言 |

这些是面向用户的分析摘要、计划和可核验的工具事实；不展示模型私有草稿或系统提示词。模型未返回方案字段时不补写方案；无执行事件时不标记成功。失败查询不会合成“已返回数据”；没有活动摘要的旧记录只展示可核对的已有结果。

业务活动使用白名单字段生成，原始 SQL 和模型 notes 不直接进入公开摘要。结果和 workflow SSE 统一走字段权限投影；隐藏数据集名称时同时隐藏可能包含来源名的自由文本方案。公开过程不依赖用户拥有技术诊断权限，SQL 和诊断入口继续按控制台权限开放。

## 输入框动效

执行时高亮沿输入框四周连续运行，使用背景裁剪只画边框，不旋转或阻塞内部输入。仍可输入、排队与停止。启用减少动态效果时改成静态边框。浏览器验收检查边框与输入框高度一致，避免再次退化成顶部细条。

## 验证范围

- 后端 71 项测试通过：包含角色分配优先、分配清理与非法值过滤、公开活动不包含原始 SQL/notes、来源隐藏策略。
- 前端 20 项测试通过：包含活动按分支去重、失败结果不生成数据事实，及原有状态和队列逻辑。
- 浏览器回归通过：隐藏路径选择、服务端策略驱动两条流程、角色设置保存、计划确认、证据报告、队列、四周动效与响应式。
- 本地部署后另使用模拟燃气数据做真实模型验收，结果与截图单独保存于“升级验收截图/角色分流与分析内容”。真实模型验收与隔离接口回归分开记录。
