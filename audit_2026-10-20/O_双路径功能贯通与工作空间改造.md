# 双路径功能贯通与工作空间改造

日期：2026-10-22。已部署到本地 `http://localhost:8888`。本轮在现有业务代码上实施，保留原路由、内部角色编号、组织树、业务数据和模型配置。

## 全站入口

取消横向平铺菜单，采用浅色侧栏、紧凑页面工具条、底部账号菜单。管理员账号固定左下角，向上打开控制台、修改密码与退出登录菜单。手机使用可关闭的导航抽屉。

分组为分析工作区、数据资产、问数编排、组织治理、系统运维。菜单、命令搜索、路由准入和缓存页继续使用同一份角色与功能权限过滤。系统控制台成为明确导航入口。未改造权限模型；服务端仍做授权检查。

问数历史取消深色常驻栏，改为顶部“最近分析”抽屉：完整问题优先、数据集、时间、搜索、日期分组、当前记录标记；删除、清空与新分析沿用对应控制台功能位。运行期间可浏览但不能切换记录，保留任务保护。历史数据仍按账号隔离，未清空、重建或合并用户记录。

## 角色与流程

“智能体管理 / AGENT 管理”统一为“专家协作”。保留四个真实配置角色，不虚构新的可执行角色：

| 内部编号（兼容既有接口） | 显示职责 | 实际使用 |
| --- | --- | --- |
| 1 | 主理人 · 路由与研究规划 | 普通问题范围识别、路由；高阶研究规划 |
| 2 | 查询专家 | 两条路径的 SQL 生成、字段映射与有界修复 |
| 3 | 核验专家 | 两条路径的 SQL、字段与口径复核 |
| 4 | 分析与报告专家 | 普通结果解读、高阶证据摘要与报告 |

领域上下文由数据集、指标、关联、样例和专家提示片段提供；高阶运行器将任务拆为受权限隔离的并行分支。调度与并发预算在流程控制中维护，不能通过修改角色名字改变执行绑定。

已配置的自定义角色名字和提示词保留；仅将系统自带旧角色名字映射为新的展示名。配置页连接“技能与工具”和流程策略，技能详情可跳转至绑定专家。数据集、报告模板、迁移页面中的相关可见术语同步调整，原 API 字段与旧路由继续兼容。

## 技能编辑与执行绑定

“进阶能力”改为“技能与工具”，新增两条路径的能力地图、共享/高阶筛选和配置抽屉。内部执行标识移入详情，避免主表暴露过多技术列。

新增显式共享技能：组织范围校验、字段关联与剪枝、指标口径对齐、执行计划预检、数据合理性断言。与原有 16 项能力合并为 21 项内置能力。

| 配置类型 | 可编辑内容 | 真正生效位置 |
| --- | --- | --- |
| 专家指令 | 名称、说明、最多 6000 字的执行指令 | `instructions_for` 根据角色与路径注入 `_get_agent_prompt`；保留原系统提示词与知识 |
| Schema 剪枝 | 字段检索数量，8–160 | 真实生成上下文与高阶分支字段关联；组织、时间、关系键继续保留 |
| 固定护栏 | 名称、说明 | SQL 只读、行级权限、EXPLAIN、结果断言继续由固定执行器处理，文本不能关闭或替换安全校验 |
| 高阶诊断 | 名称、说明、允许的启用状态 | 已有的高阶结果诊断执行器；没有支持的指令入口时不显示可生效的指令输入框 |
| 导入扩展 | 配置资料存档 | 明确标注无执行器；不执行任意代码、不伪造工具调用 |

绑定角色由服务端定义，客户端不能提交伪造 runtime 元数据绕过。必要技能在服务端归一化时始终开启；字段参数被限制范围。共享技能不随高阶能力总开关关闭。普通问数同步读取金标检索策略，高阶按已确认计划的技能快照执行；高阶总关闭仍会阻止后续确认。

MCP 工具仍为配置接入口，未在本轮接通任意外部执行器；飞书同步没有新增连接或启动任务。没有把“导入配置成功”当作“执行器可用”。

## 控制台状态协同

默认普通问数并不代表高阶研究未生效。高阶开放状态与默认路径分别显示；具体是否准入继续由角色、数据集和控制台策略共同决定。技能读取接口返回只包含默认路径与高阶总开关的入口摘要，管理员不必拥有超级管理员的完整策略接口权限，也能看到准确状态。

保存、导入、恢复默认的后端接口补充对应功能位校验，保留管理员角色门槛和原系统超级管理员规则。控制台标题统一为“双路径问数控制”，移除错误的自动回落提示。
