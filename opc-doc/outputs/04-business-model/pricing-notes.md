# 收费方式假设（Pricing Notes）

## 定价锚点
"省一个 BI 人力"（30 万+/年），而非对标 BI 软件 License。客户替代方案是"招人或忍着"，年费 10–25 万区间 ROI 最好算。

## 各通道价格假设
| 通道 | 收费结构 | 价格假设 |
|---|---|---|
| S1 直销 | 软件年费 + 首年口径实施费（两段式） | 年费 12–20 万（按数据域分级）+ 实施费 5–10 万 |
| S2 ISV | License 费 或 项目分成 + 认证培训费 | 5–8 万/客户/年 或 终端合同额 20–30%；培训 2–5 万/家 |
| S3 渠道 | 目录价折扣拿货（阶梯返佣） | 渠道 6–7 折，设最低成交价 MAP |
| S4 联合交付 | 项目分成 | 创始方 50–60%，咨询方 40–50%；软件续费归创始方 |
| 托管订阅 | 年订阅（License+运维+错题库更新） | 15–25 万/年；SLA 旗舰版溢价 50%+ |

## 待验证假设
- S1 客户对 10–25 万年费的真实接受度（MVP 阶段 3 个 PoC 议价实测）
- ISV 对"License 费 + 禁白牌"组合条款的接受底线
- 托管订阅的服务成本能否被半自动化错题回归压到可承受区间
