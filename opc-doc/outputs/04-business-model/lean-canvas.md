# Lean Canvas — DataPulse 对外商业化

| 模块 | 内容 |
|---|---|
| **Problem** | ① 中型企业养不起 BI 团队（30万+/人/年）② 传统 BI 实施 3–6 个月 ③ 通用 ChatBI 接不了飞书多维表格且算错数、信任归零 ④ 核心经营数据不敢上公有云 |
| **Customer Segments** | S1 飞书原生无 BI 团队的中型制造/消费品企业（主锚点）；S2 数据咨询/实施商 ISV（规模化杠杆）；S3 SaaS 渠道商（通路）；S4 大型企业集团数字化部门（灯塔） |
| **Unique Value Proposition** | 长在飞书数据上的企业级智能问数平台：大白话问到"对得上账"的经营数据，私有化部署，今天装、明天问 |
| **Solution** | 四 Agent 问数平台 + 飞书多维表格原生同步 PostgreSQL 语义层 + 口径手册/错题库质量工程 + Docker 一键私有化交付 |
| **Channels** | 自营直销（0→1，攒 SOP 与案例）→ ISV 授权 + 咨询联合交付（1→10）→ 渠道分销（10→N，产品标准化后启动） |
| **Revenue Streams** | 软件年费 10–25 万（S1）+ 首年口径实施费 5–10 万 + ISV License 费 5–8 万/客户/年或 20–30% 项目分成 + 渠道折扣差 + 托管订阅 15–25 万/年 |
| **Cost Structure** | 创始人时间（最大成本，在职兼职约束）、P0/P1 产品化改造、法务与软著费用、Demo 环境云资源、售后托管人力 |
| **Key Metrics** | 准确率验收通过率（对账吻合度）、次年续费率 NRR、单客户交付周期（天）、ISV/渠道单均年产出、错题库回归通过率 |
| **Unfair Advantage** | 真实集团业务长出的《口径手册》+《100 大经典错题库》（不可再生、抄不走）+ 飞书原生×私有化组合卡位 + 智问科技真实背书 |
