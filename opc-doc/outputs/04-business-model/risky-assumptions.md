# 高风险假设清单（供 MVP 阶段优先验证）

| 优先级 | 假设 | 失败后果 | 验证方式 |
|---|---|---|---|
| 🔴 P0 | **权属假设**：DataPulse 职务作品边界可厘清（拿到雇主书面确认或完成主体/代码切割），商业化签约主体合规成立 | 全部商业化成果归属存在争议，"当嫁衣"风险从合作方扩大到雇主层面 | 律师咨询 + 与雇主书面确认（谈合作前必做） |
| 🔴 P1 | **付费假设**：S1 客户愿为智能问数付 10–25 万/年，而非继续人肉导表 | 定价体系整体下修，五方案收入模型重算 | 3 个自营 PoC 的转化率与议价过程实测 |
| 🟡 P2 | **可复制假设**：口径实施可从创始人手艺变为 ISV 照 SOP 可执行的标准动作（4–6 周交付） | 方案 2/3 规模化通路关闭，生意锁死在创始人时间上 | 首个 ISV 认证项目实测交付周期与验收通过率 |
| 🟡 P3 | **续费假设**：次年纯软件年费续费率 ≥ 80%（口径资产沉淀后客户离不开） | 收入模型从年金退化为一次性买卖，估值逻辑改变 | 首批客户 12 个月后续费数据 |
| 🟢 P4 | **资产保护假设**：License + 闭源 + 三禁条款足以防止 ISV 白牌/自研 | 护城河外流（可通过合同罚则 + 水印溯源事后救济） | 合同执行观察 + 镜像水印抽检 |
