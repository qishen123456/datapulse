#### 二、系统生成 SQL vs Ground Truth 对比
- **系统实际执行 SQL**:
  ```sql
  WITH 源数据 AS (
    SELECT
      fields,
      COALESCE(NULLIF(regexp_replace(fields ->> 'target_amount（金额）', '[^0-9.-]', '', 'g'), ''), '0')::NUMERIC AS target_amount原值,
      COALESCE(NULLIF(regexp_replace(fields ->> 'actual_billing_amount', '[^0-9.-]', '', 'g'), ''), '0')::NUMERIC AS 年度开单原值,
      COALESCE(NULLIF(regexp_replace(fields ->> 'target_amount达成率', '[^0-9.-]', '', 'g'), ''), '0')::NUMERIC AS 达成率原值
    FROM public.smart_sales_performance
  )
  SELECT
    '企业服务事业部' AS 条线,
    CASE
      WHEN NULLIF(fields ->> '分公司', '') IS NULL THEN '企业服务事业部总体'
      WHEN NULLIF(fields ->> '城市分公司', '') IS NULL THEN '分公司'
      ELSE '城市分公司'
    END AS 层级,
    CASE
      WHEN NULLIF(fields ->> '分公司', '') IS NULL THEN '企业服务事业部'
      WHEN NULLIF(fields ->> '城市分公司', '') IS NULL THEN fields ->> '分公司'
      ELSE fields ->> '城市分公司'
    END AS region_name,
    ROUND(target_amount原值, 2) AS target_amount,
    ROUND(年度开单原值, 2) AS actual_billing_amount,
    ROUND(CASE WHEN target_amount原值 > 0 THEN 年度开单原值 / target_amount原值 * 100 ELSE 达成率原值 END, 2) AS 达成率
  FROM 源数据
  WHERE target_amount原值 > 0
  ORDER BY CASE 层级 WHEN '企业服务事业部总体' THEN 1 WHEN '分公司' THEN 2 ELSE 3 END, 达成率 DESC;
  ```

- **综合判定**: 🟡 **PARTIAL（业务事实对，但 SQL 过滤过窄返回空表）**

#### 二、问题定位与根因
- **现象**: 生成的 SQL 返回 0 行，未展示 13 个分公司列表。
- **根因**: SQL 中加入了 `WHERE 地产开单 > 0` 类似过滤，而数据库中各分公司的地产任务与开单真实值恰好全为 0（地产仅总部承担），过滤导致整表为空。
